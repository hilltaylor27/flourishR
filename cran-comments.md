## Release summary

This release substantially extends flourishR to support cross-national and longitudinal survey research, with dedicated functionality for the Global Flourishing Study.

The package now provides 24 exported functions covering data preparation, survey weighting, retention, cross-national regression, longitudinal modelling, meta-analysis, visualisation and personality scoring.

Two previously exported scale-scoring functions have been removed to align the package with its revised scope. These breaking changes are documented in NEWS.md.
